Import

New sign-ups sync in automatically while you're logged in (every minute, or use Sync now in the header). The CSV import below is a manual fallback: Netlify → Forms → volunteer-signup → Download CSV. Existing volunteers are matched by email and updated.

Reset

The roster is saved on the server and shared by all admins; changes save automatically. "Clear everything" and "Load sample data" change the shared roster for everyone. Download a JSON backup now and then as a safety copy.
